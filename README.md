
A browser-playable platform game and level editor. Open `index.html` in a modern browser. Phaser 3.80.1 is loaded from a CDN, so an internet connection is required on first load.

## New features
- Larger 50 × 32 tile world with vertical exploration and camera follow
- Five selectable character colours
- Adjustable travel range (2–12 tiles) for moving platforms, chainsaws, and boulders
- Chainsaws, falling spikes, and rolling boulders
- Temporary Fireproof, Invisibility, Armour, and Double Jump power-ups
- Existing editor tools, checkpoints, keys, crates, springs, ice, conveyor belts, fire, spikes, undo/redo, level codes, and local save

## Controls
- Move: A/D or Left/Right arrows
- Jump: Space, W, or Up arrow
- Restart: R
- Return to editor: Esc
- Editor: click/drag to place; right-click to erase; mouse wheel to scroll vertically; Shift + wheel to scroll horizontally
- Select tools from the palette; set moving-object travel range with the toolbar slider

The default level is a vertical expedition. Build and test your own levels before sharing their level codes.
